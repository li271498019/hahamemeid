# haha.meme 网站规划 v0.1

> 状态：规划稿（2026-11-20）。合约接口与地址以 D 交付的合约为准，接口定稿后补充 `skill.md` 与每条指令的 calldata。

## 1. 交互模式（核心原则）

网站**不接入任何钱包套件**，不碰私钥，不发交易。所有写操作都由用户自己的 AI agent 通过 Binance Agentic Wallet 完成。

1. **只读登录（全站通用）**：顶部导航栏输入 `.ai` 名字 → 调用币安 Agent ID 注册表 `0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F` 的 `ownerOfHandle(handle)` 得到地址 → 全站以“观察模式”展示该地址的数据（我的域名、积分、签到状态、冷却剩余时间等）。登录状态保存在浏览器本地，可随时切换或退出。
2. **指令按钮**：每个写操作按钮只生成一段已填好参数的自然语言指令，用户点击复制，粘贴给自己的 agent 执行。
3. **agent 说明书 `https://haha.meme/skill.md`**：agent 读完即知道项目是什么、调用哪个合约哪个函数、calldata 怎么拼、如何用 `baw` 预览并执行交易、报错怎么处理。

### 指令模板（通用结构）

```
用我的 Binance Agentic Wallet 执行以下任务。若当前环境没有 Agentic Wallet skill，先安装：
npx skills add binance/binance-skills-hub --skill binance-agentic-wallet
若需要登录，我登录完成后会回复「继续」，届时从这里接着执行。
阅读 https://haha.meme/skill.md，按其中规则在 BNB Chain 上【具体任务，参数已填好】。
先确认 Developer Mode 已开启，把交易预览给我看，我确认后再执行。
```

【具体任务】示例：铸造 `abc123.meme`；今日签到；领取关注任务积分；把 `abc.haha` 设为主域名；激活 `abc.haha` 的 agent 身份；给 `xyz.haha` 打 5 星并写一句评语；以 0.5 BNB 挂单 `abc.haha`；购买挂单中的 `abc.haha`。

说明：域名参数是字符串，ABI 编码比纯数字复杂，网站生成指令时尽量直接附上编码好的 calldata，降低 agent 出错率。

## 2.5 视觉风格（2026-11-20 定方向，设计稿由项目方拍板）

- **整体气质**：轻快、俏皮、meme 感强，有设计感，细节满满。
- **配色**：橙黄白色系。主背景为比特币橙（参考 #F7931A），搭配 NFT 的橙黄渐变（#FFC21A → #FF7A1A），白色文字，粗体字体。
- **meme 元素**：用一套原创硬币插画。不使用第三方币种标志或商标，不画真人面孔。不做 Pepe，也不另画青蛙角色。币雨里的青蛙硬币除外，它只作为硬币图案。
- **鼠标互动**：用普通光标，不用跟着转的光环。鼠标碰到下落的硬币时，这枚硬币停下、变为不透明并高亮；离开后恢复半透明并继续下落。点一下会弹起、翻转，溅出小笑脸和 +1，再从顶上重新落下。
- **背景动画**：原创硬币缩小后铺满画面，半透明下落。桌面大约 120 枚，手机大约 48 枚。18 个图案循环使用，落出底部再从顶上回来。
- **积分图标**：数字旁边只用像素风金色笑脸硬币，不写「积分」二字。这枚硬币就表示积分。
- **标志**：导航用拍板的笑脸金币 `web/site/assets/logo/haha-logo-nav-64.png`，放在「haha.meme」旁边。
- **性能与体验**：动画用 Canvas。支持系统「减少动态效果」，开启后硬币静止。

### 页面 1：haha id（搜索与铸造）

- 页面中央一个大搜索框，右侧 `.haha` / `.meme` 切换按钮，用户选择要铸造的后缀。
- 输入时实时做规范化与校验（小写，只允许 a-z0-9，3–32 位）。
- 搜索结果三种状态：
  - 黑名单 / 保留名 / 1–2 位 / 非法字符：**该名称不可铸造，换一个试试吧！**
  - 已被铸造：**来晚啦！该名称已经被铸造！**（附持有人、是否在售，在售则可跳转市场）
  - 可铸造：**复制指令，快去找你的agent铸造吧！**（显示“复制指令”按钮和 SVG 预览图）
- 已登录时显示：是否持有 `.ai`、1 小时冷却剩余时间。
- 黑名单只在前端用加盐哈希比对，不明文展示词表。

### 页面 2：交易市场

- 类 OpenSea 网格布局，只展示卖家挂单：NFT 图片（链上 SVG）、名称、价格（BNB）、折合美元。
- 顶部统计栏：手续费规则（成交收取 1%，卖家支付；外部市场版税 1%）、24 小时成交量、最后一单成交价、地板价、挂单量。
- 最近成交列表。
- 搜索框：可直接搜完整名称，比如 `abc123.meme`。
  - 挂单中：显示价格和“复制购买指令”。
  - 已铸造未挂单：显示“该名称暂未出售”。
  - 未铸造：引导到 haha id 页面铸造。
- 勾选式筛选（可多选）：
  - 后缀：`.haha` / `.meme`
  - 3 位纯字母、3 位纯数字、3 位字母数字组合
  - 4 位纯字母、4 位纯数字、4 位字母数字组合
  - 5 位以上纯字母或纯数字、5 位以上字母数字组合
  - 其他：不属于以上任一类的名称（实际为管理员铸造的 1–2 位保留名），建议展示为“1–2 位稀有名”
- 排序：价格从低到高 / 从高到低、最新挂单。
- 卖家操作（我的域名卡片上）：复制“挂单 / 改价 / 撤单”指令；买家：复制“购买”指令。
- 页面提示：域名转手后 ERC-8004 agent 身份销毁、信誉清零，买到的是域名，不含信誉。

### 页面 3：ERC-8004

- **我的域名**：列出已登录地址持有的全部 `.haha` / `.meme`，每个域名可复制指令：激活 agent、设为主域名、设置解析地址、设置文本记录（介绍、服务链接等）。
- **agent 广场**：所有已激活 agent，支持按评分、评价数、最新激活排序。
- **agent 名片页**（`/agent/abc.haha`）：头像（复用域名 SVG）、绑定地址、介绍与服务链接、星级评分、评语列表、“复制评价指令”。
- **打分规则展示**：仅 `.ai` 持有人可评，每个 `.ai` 对同一 agent 一条评价（可修改），不能给自己打分，1–5 星，评语 140 字节以内，由 agent 生成。
- **信誉排行榜**。
- **最新评价**：滚动展示链上评价事件。

### 页面 4：任务（积分）

- 我的积分、今日已完成 / 未完成任务。
- 每日签到：30 分 / UTC 天。
- 铸造任务：每次 10 分，每天最多 3 次。
- 社交任务（伪验证）：关注 30 分（一次性）；点赞、转发、评论各 10 分 / 天。
- 每个任务一个“复制指令”按钮。另提供“每日例行”指令：让 agent 每天自动完成签到和可做的任务。
- 积分排行榜。
- 规则说明：必须持有 `.haha` 或 `.meme` 才能参与；积分绑定 `.ai`，不可转让。

- 后续小游戏通过积分 earner 接口加分（补充规格在 D 当前交付之后、主网部署之前完成）。

### 页面 6：工作原理（面向用户的项目文档）

目标：用户一看就知道 haha.meme 是做什么的、怎么运作、为什么可信。内容全部公开透明，链接到 BscScan 可验证。

1. **项目是什么**：基于 Binance `.ai` Agent ID 的 AI agent 链上身份协议，`.haha` / `.meme` 两个后缀，结合 ERC-8004 身份与信誉。
2. **怎么用**：只读登录 → 复制指令 → agent 读 `skill.md` → 预览 → 用户确认 → 执行。附 Binance Agentic Wallet 安装与开发者模式开启说明。
3. **铸造规则**：持有 `.ai` 才能铸造；免费、永久、无需续费；数量和总量不限；两个后缀共用 1 小时冷却；只能铸造给自己；3–32 位 a-z0-9；1–2 位及保留名不可公开铸造；违规词黑名单硬编码、永久冻结（只说明机制，不公开词表）。
4. **域名解析**：正向解析（未设置时默认指向持有人）、反向解析（主域名，手动设置）、文本记录；转让后解析地址与文本记录自动清空。
5. **ERC-8004**：自愿激活 agent 身份；信誉规则（仅 `.ai` 持有人、每人一条可修改、不能自评、1–5 星、评语 140 字节以内）；域名转让后 agent 身份销毁、信誉清零。
6. **积分**：完全上链、不可转让、绑定 `.ai`；各项任务分值和次数；须持有 `.haha` / `.meme`；积分用途（未来拍卖、游戏）。
7. **交易市场**：挂单—购买模式，仅 BNB，成交手续费 1%（卖家支付，永久写死）；外部市场版税 1%。
8. **NFT 与艺术**：完全链上 SVG，不依赖服务器或 IPFS；集合名 `haha id`，符号 `HAHAID`。
9. **去中心化与权限**：
   - 全部合约不可升级、无代理，部署后谁也改不了。
   - 管理员仅三项权限：铸造保留名、修改积分分值、授权/撤销积分消费合约。
   - 管理员永远不能拉黑用户地址、不能动用户 NFT、不能改手续费。
   - 部署者地址部署后零权限。
10. **合约与地址一览**（主网部署后填写，每个附 BscScan 链接，并注明已开源验证）：
    - 10 个合约：Policy、Registry、Registrar、Resolver、Metadata、AgentIdentity、Reputation、Points、Marketplace、部署工厂。
    - 币安 `.ai` 注册表：`0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F`
    - 管理员：`0x083A467259f12602E9053bBAe2b3Fd5B62976Ef7`（硬件钱包，不可更换）
    - 手续费与版税接收地址：`0x57A76124bC919F7509bEb54924E8448258De90df`
11. **审计与开源**：审计报告、GitHub 仓库链接。
12. **风险提示与常见问题**：链上操作不可撤销；每次执行前务必核对预览；非币安官方项目。

## 4. `skill.md` 结构（接口定稿后填写）

1. 项目简介：haha.meme 是什么，`.haha` / `.meme` 与 `.ai` 的关系。

4. 使用前检查：`baw wallet status`、开发者模式已开且额度够、`baw wallet address`、`baw wallet agent-id` 已认领、BNB 余额够 gas。
5. 每个操作：函数签名、参数、calldata 拼法、msg.value。
6. 写交易流程：先 `eth_call` 模拟 → `baw contract-call preview` → 给用户看预览 → 用户确认 → `baw contract-call execute`。
7. 读接口：可用性、冷却、积分、今日任务状态、挂单、信誉等。
8. 报错 selector 与含义、处理方式。
9. 每日例行任务流程。
