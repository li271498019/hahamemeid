# Haha Dog 合约开发文档 v1.0（已冻结 2026-11-28）

## 1. 项目
- 合集名：Haha Dog
- 品牌：Haha AI，链上运行的 AI 大模型
- 链：BSC 主网
- 全部合约开源，不可升级
- 现有 12 个合约和网站不改

## 2. 合约清单（共 4 个）
| 合约 | 作用 |
|---|---|
| HahaDogModel | 存放 10,048 个 int8 参数，整数推理：种子 → 16×16 狗 + 配色。已完成，与 Python 逐位一致 |
| HahaDogRenderer | 5 种背景、SVG、属性、稀有度、tokenURI（base64 JSON）、"出图中"图。已完成 |
| HahaDog（ERC-721） | 铸造、资格、名额、随机数、哈希快照、重铸、EIP-2981 版税 |
| HahaDogMarket | Haha Dog 专用交易市场 |

- 模型权重 keccak256：`0x1d2239644b5273c4f1925c489d32900a564262bce6597f94a929489cfbe58078`
- 稀有度、背景、属性、SVG 规则与网站 /ai 页完全一致，冻结后不得更改

## 3. 铸造
- 总量上限：10,000
- 铸造免费（只付 gas）
- 准入：必须持有 .ai（Binance 灵魂绑定域名）
- 名额：持有 .ai 得 1 个；同时持有 haha id 再加 1 个；最多 2 个
- 名额绑定在 .ai 身份上，不是钱包；.ai 或 haha id 怎么转移，同一个 .ai 一共最多 2 个
- .ai 判断：复用仓库现有 `HahaAiIdentity.aiIdentityOf`
- haha id 判断：`HahaRegistrar.balanceOf(用户) > 0`
- 不设开始时间，部署即开放

## 4. 随机数（无揭示）
- 铸造或重铸时记录当前区块 N，结果在提交时即锁定
- 种子 = keccak256(blockhash(N+4), tokenId, 重铸次数)
- 没有揭示步骤：第 N+4 块出来后，tokenURI 直接读取 blockhash(N+4) 现场出图，用户无需任何操作
- N+4 块出来之前显示"出图中"图
- 哈希快照：合约提供任何人可免费调用的快照函数，把已到期的目标块哈希写入合约 storage，写入后永久有效；铸造、重铸、转账时自动执行一次快照；项目方运行定时调用快照的程序（它只是普通调用方，不保存、不决定任何数据）
- 若 BSC 支持 EIP-2935（最近 8191 块哈希），读取时一并使用，延长窗口
- 若目标块哈希超出可读窗口且未被快照：token 显示"出图中"状态，持有人可免费重铸；不给任何兜底图或替换图
- 全程无任何费用、无押金、无罚没（只付 gas）

## 5. 重铸
- 不限次数，免费
- 只有持有人可重铸
- 重铸提交时旧图立即作废，不可恢复，新图在 N+4 自动出现

## 6. 交易市场 HahaDogMarket
- 规则与现有 HahaMarketplace 一致：成交收 1% 手续费，进入现有手续费地址，提取制
- HahaDog 合约声明 EIP-2981 版税 1%，收款为手续费地址（只对外部市场生效）
- 尚未出图、或挂单后被重铸的 token 不能成交
