- `backups/website-new-20261127.tar.gz`：2026-11-27 的网站备份包。解包内容已扫描，没有密钥或服务器 IP。

This directory is historical. The live site is `website/`, and the live indexer is `indexer/`. `root-site/` is the pre-`web/site` pages that used to sit at the private repo root. The tarball is the 2026-11-27 website backup; its contents were scanned and contain no keys or server IPs.
