API 文档

公开 API

基础地址 https://haha.meme/api，无需鉴权，全部是 GET，返回 JSON。数据来自索引器，只读已确认区块。

1. 通用规则

全部是 GET。POST 返回 405。未知路径返回 404。uint256（tokenId、价格、积分）用十进制字符串表示。地址是小写 0x 开头。时间是 UTC ISO-8601，带 Z。分页：limit 默认 24，范围 1–50；cursor 是不透明字符串，从上一页的 nextCursor 取；nextCursor 为 null 表示没有更多。空列表返回 200 和 items: []。

2. 限流

nginx 按 IP 限流。正常浏览、正常调用不受影响。短时间内请求过多会返回 429 和 Retry-After，等一会儿再试。不要用高并发刷接口。

3. 健康检查

索引器是否健康，safeBlock 和落后区块数。路径是 /api/health，不是 /api/v1/health。ok 为 true 要求 safeBlock 存在且落后不超过 40 块。

GET /health

{
  "ok": true,
  "chainId": 56,
  "safeBlock": 135053891,
  "headBlock": 135053897,
  "lagBlocks": 6,
  "lastError": null
}

示例: curl "https://haha.meme/api/health"

7. 信誉榜

按平均分排序的信誉榜，只含活跃 agent。参数：limit（默认 24，1–50）、sort（只有 stars_desc）、minReviews（最少评价数，默认 1，1–20）、cursor（翻页）。每条另加 rank（从 1 起，跨页连续）。

14. 主名反查

输钱包地址，返回它的主名。路径参数是 address（0x + 40 位十六进制）。没有主名时 primaryName 为 null。主名直接读链上 HahaResolver.primaryName，永远是当前值；链上读失败返回 502。

GET /v1/owners/{address}/primary

{
  "owner": "0xe40a0c726fd2f990713ade7380c89800f4e8ac49",
  "primaryName": "tst1234.haha"
}

示例: curl "https://haha.meme/api/v1/owners/0xe40a0c726fd2f990713ade7380c89800f4e8ac49/primary"

15. NFT 图片

一个名字的 NFT 图片，就是链上的 SVG。返回的不是 JSON，是 image/svg+xml。名字从未铸出返回 404。图片由索引器在本地生成，和链上 SVG 逐字节一致。tst1234.haha 的图是 5592 字节。缓存 public, max-age=14400。

GET /v1/names/{fullName}/image.svg

示例: curl "https://haha.meme/api/v1/names/tst1234.haha/image.svg"

16. NFT metadata

一个名字的 NFT metadata，标准 tokenURI 风格的 JSON。名字从未铸出返回 404。image 是指向上面的 /image.svg 接口的 HTTP 地址。说清楚一点：这个接口不能让标准钱包自动显示 NFT，因为 HahaRegistrar 没有 tokenURI（V1 合约的限制，不可升级）。

GET /v1/names/{fullName}/metadata

{
  "name": "tst1234.haha",
  "description": "haha.meme agent identity for tst1234.haha",
  "image": "https://haha.meme/api/v1/names/tst1234.haha/image.svg",
  "attributes": [
    {"trait_type": "TLD", "value": "haha"},
    {"trait_type": "Length", "display_type": "number", "value": 7}
  ]
}

示例: curl "https://haha.meme/api/v1/names/tst1234.haha/metadata"

17. 说明

之前计划中的两个接口已经上线：主名反查（第 14 节）和 NFT metadata（第 16 节）。还有一个限制：metadata 接口不能让标准钱包自动显示 NFT，因为 HahaRegistrar 没有 tokenURI（V1 合约的限制，不可升级）。

18. 错误

400 是参数不对（limit / sort / cursor / tld / 名字 / minReviews / 地址），404 是路径不存在或历代查了未铸的名字，405 是只支持 GET，429 是请求过多（等 Retry-After 再试），500 是服务器内部错误。
