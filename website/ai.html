Haha AI
链上运行的 AI 大模型

Haha AI 是一个训练出来的神经网络。它的权重写在智能合约里，推理也在合约里完成：给它任意一个种子，它就现场算出一只像素狗。没有服务器，没有 IPFS，图片不是事先画好存上链的，每次查看都由模型在链上重新算一遍。

模型结构

VAE 解码器 · ReLU · int8 权重
  1. 种子bytes32任意 32 字节
  2. 种子编码 z8 × int8每 4 字节相加
  3. 隐藏层 164 · ReLU576 个参数
  4. 隐藏层 232 · ReLU2,080 个参数
  5. 输出层224198 个像素坐标 + 26 个配色分数 · 7,392 个参数
  6. 像素狗16×8 → 16×16左半边镜像成整张脸
  7. 合约出图24×24 SVG加上背景，tokenURI 直接返回

整个计算只有整数加法、乘法、移位和比较，没有浮点数。所以智能合约、这个网页和开源的 Python 程序，用同一个种子算出来的结果逐位相同。

为什么参数这么少？链上每个字节都很贵，单个合约最大 24KB。Haha AI 把一个完整训练出来的生成模型压进约 10.7KB，全部放在链上运行。

3. 训练报告

1,000只原创像素狗素材
VAE + OT变分自编码器 + 最优传输
99.7%int8 与训练模拟的像素一致率
397 / 400随机抽样里不重复的造型
≈7格：生成图与最像素材的平均差异

训练分三步：先训练一个变分自编码器（VAE），再用最优传输把随机种子一一配对到素材狗上继续训练，让任意种子都能画出干净的狗；最后 30% 的轮次在 int8 模拟下训练（QAT），保证量化成整数后几乎不变。生成的狗平均和最像的素材也差约 7 格，说明它是在组合新造型，不是在抄素材。

4. 自己复现

  1. 从公开库下载 Haha AI 训练包，在 haha-ai/ 目录： haha-ai/
  2. 安装 Python 3.10 或更新的版本。Windows 安装时勾选 “Add python.exe to PATH”。
  3. 在训练包文件夹里打开命令行，安装依赖：
    pip install -r requirements.txt
  4. 一键训练。普通电脑 CPU 约 8–20 分钟，不需要显卡；加 --fast 可以先一分钟试跑：
    python run_all.py
  5. 用公布的权重算任意种子，和本页“在线生成”的结果对照：
    python infer_int.py weights-int8.json <64 位十六进制种子，不带 0x>
  6. 核对权重哈希：sha256 可以用系统命令，keccak256 用本页的“权重哈希校验”。
    sha256sum weights-int8.json
certutil -hashfile weights-int8.json SHA256

训练有随机性，自己重新训练出来的权重数字会不一样，但画出来的是同一种风格的狗，这正是“训练出来”和“手写出来”的区别。要和链上逐位一致，请用公布的 weights-int8.json。
