1. 通用规则

全部是 GET。POST 返回 405。未知路径返回 404。uint256（tokenId、价格、积分）用十进制字符串表示。地址是小写 0x 开头。时间是 UTC ISO-8601，带 Z。分页：limit 默认 24，范围 1–50；cursor 是不透明字符串，从上一页的 nextCursor 取；nextCursor 为 null 表示没有更多。空列表返回 200 和 items: []。

2. 限流

nginx 按 IP 限流。正常浏览、正常调用不受影响。短时间内请求过多会返回 429 和 Retry-After，等一会儿再试。不要用高并发刷接口。

3. 健康检查

索引器是否健康，safeBlock 和落后区块数。路径是 /api/health，不是 /api/v1/health。ok 为 true 要求 safeBlock 存在且落后不超过 40 块。

GET /health

{
  "ok": true,
  "chainId": 56,
  "safeBlock": 135053891,
  "headBlock": 135053897,
  "lagBlocks": 6,
  "lastError": null
}

示例: curl "https://haha.meme/api/health"

8. 验证

ERC-8004 验证注册表的只读接口和上传接口。GET 查一个 agent 的全部验证记录，或按请求哈希查一条；POST 上传请求文档，验签后自动发布。验证结果是 0–100 的分数，100 表示通过，0 表示没通过；v1 验证者为项目管理员。

GET /v1/agents/{agentId}/validations

GET /v1/validations/{requestHash}

POST /v1/validations/upload

上传请求文档。请求体：agentId（数字）或 fullName（至少一个）、tag（endpoint-reachable 或 identity-verified）、version（数字，对应 URL 里的 v{n}，默认 1）、document（请求文档 JSON 对象）、signature（对 requestHash 的签名，EIP-191 或 EIP-712；身份真实性时用文档里的 signature，接口可达时在请求体里单独传，签名不存进文档）。接口先算 requestHash、恢复签名地址、与链上 ownerOf(agentId) 比对，任一步失败都拒绝，不写文件。成功返回 URL 与 requestHash。同一 agent 一天最多成功上传 10 次。文档 URL 格式为 https://haha.meme/validations/{fullName}-{tag}-v{n}.json，tag 用短写（identity-verified → identity，endpoint-reachable → endpoint）。错误：400 是文档不对（bad_body、bad_tag、bad_version、document_invalid）、403 是签名不对或不是 agent 主人（signature_invalid、not_agent_owner）、404 是 agent 不存在（agent_not_found、name_not_found、no_active_agent）、429 是超过每天 10 次（rate_limited）。

{
  "agentId": 30,
  "tag": "identity-verified",
  "version": 1,
  "document": {
    "type": "identity-verified",
    "signature": "0x…",
    "signatureType": "eip712"
  }
}

示例: curl "https://haha.meme/api/v1/agents/30/validations"

20. 错误

400 是参数不对（limit / sort / cursor / tld / 名字 / minReviews / 地址），404 是路径不存在或历代查了未铸的名字，405 是只支持 GET，429 是请求过多（等 Retry-After 再试），500 是服务器内部错误。

21. 第一季

稀有域名空投第一季的只读接口。dayIndex 是 UTC 日期（2026-11-24 是 20781，每天加 1，到 2026-12-09 的 20795）。aiId 是 .ai 的 id（keccak256 哈希，0x 开头）。

某一天的根、快照块、已确认数、名额和开放状态。这一天还没有记录时返回 404。rootMatch 是索引器重算的根与链上根是否一致；opened 是当天是否已开放兑换。网站就是靠这两个值都为真才显示“已开放”。

21.7 当天任务包

某一天的每日验证任务包。返回的不是 JSON，是原始文件字节（application/octet-stream），按原字节取回，哈希要与链上 taskPack 一致。这一天还没有任务包时返回 404。任务包是标准 JSON：seasonId、dayIndex、快照块号与块哈希、checks（每条是 agentId、generation、名字、期望的 count 与 sum）。

GET /v1/season1/taskpack/{dayIndex}

示例: curl "https://haha.meme/api/v1/season1/taskpack/20781"

21.8 兑换证明

21.9 每日验证签名
